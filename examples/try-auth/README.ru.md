# Проверка аутентификации

Эти интерактивные скрипты проверяют аутентификацию NDW2 и NDW4
на реальном устройстве:

```bash
pnpm --filter try-auth ndw2
pnpm --filter try-auth ndw4
```

`poll-login` проверяет вход каждые 5 секунд, например во время
перезагрузки устройства:

```bash
pnpm --filter try-auth poll-login
```

Скрипт отправляет реальные попытки входа, которые могут привести к
блокировке учетной записи. Защита ограничивает частоту попыток.
Запускайте из корня репозитория, остановка — Ctrl+C.
